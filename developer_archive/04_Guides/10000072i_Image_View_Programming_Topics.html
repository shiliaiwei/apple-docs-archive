    Introduction to Image Views

    Important All information in this document is available in NSImageView Class Reference.

    An image view displays a single image in a frame, and can optionally allow a user to drag an image to it.

    Note that an image view performs its action only when a user drags an image to it. To perform an action when a user clicks an image, use a button For more information, see Button Programming Topics.

    Organization of This Document

    Setting an Image View’s Appearance describes how to change the appearance of the image view’s image and frame. Using an Image View to Specify an Image describes how to use an image view as an image well.
