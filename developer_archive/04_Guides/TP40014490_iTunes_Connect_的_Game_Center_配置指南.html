配置 Game Center

Game Center 概述

Game Center 是 Apple 的社交游戏网络。玩家可以通过 Game Center 追踪游戏进度、邀请好友游戏，以及通过自动匹配开始多人游戏等。Game Center 方便玩家在设备上发现你的游戏，有助于提高游戏的曝光度。为游戏启用 Game Center 功能后，便可以在 App Store Connect 中输入元数据。

【注】若要将启用了 Game Center 功能的游戏添加到新的 App 套装中，该游戏必须在至少一个 App Store 店面处于“可分发”状态。如果游戏通过第三方分发平台分发，则必须至少在一个 App Store 店面上架，才能使用 Game Center 功能。

你可以按顺序完成以下步骤，也可以根据需要重复某些步骤。

必要职能：“账户持有人”职能、“管理”职能、“App 管理”职能、“开发者”职能或“营销”职能。请参见职能权限。

  1. 在 Xcode 中启用 Game Center

    在 Xcode 中创建项目，输入 App 名称和套装 ID，然后启用 Game Center。此操作会将 GameKit 框架和 Game Center 权限添加至你的项目中。进一步了解在 Xcode 中启用 Game Center。

  2. 在 App Store Connect 中配置 Game Center

    进入 App Store Connect，使用在 Xcode 中设置的套装 ID 将 App 添加到你的账户，并为 App 版本启用 Game Center，然后配置 Game Center 组件，如排行榜、成就、挑战、活动、群组和多玩家兼容性等。

  3. 实施 Game Center 功能

    在 Xcode 中为 App 添加相应代码并配置 Game Center 服务使用的组件，从而将 Game Center 整合到你的游戏中。尽管这些组件需要和你的 App 套装分开配置，但应将其与游戏代码紧密结合，以确保符合所有设计和开发规范。进一步了解。

    获取更多设计指南和建议，提升 Game Center 用户体验。

  4. 测试游戏

    通过测试确保 Game Center 组件可以单独和协同运行。Apple 支持开发者使用与已发布游戏完全相同的服务器环境来开发预发布版本，让测试员可以与任何玩家进行游戏，而非局限于测试员群体。

  5. 分发游戏

    将 Game Center 组件添加到所需的平台版本中，然后提交游戏至审核。
