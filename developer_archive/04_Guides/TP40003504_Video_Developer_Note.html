    Introduction to Video Developer Note

    Important: This document may not represent best practices for current development. Links to downloads and other resources may no longer be valid.

    This technology developer note describes details of Apple’s support for video output from Mac computers.

    Note: This technology developer note covers only Mac computers introduced after September 2005.

    Developers who are designing video cards, external display devices, or display processing software will find this note helpful.

    Organization of This Document

    This document is contains the following articles:

    • Video Concepts describes Apple's implementation of video technology on Mac computers.

    • Video Product-Specific Details provides details specific to particular Mac computers.

    See Also

    For specific information about a particular Mac computer, see the product Developer Note for that computer in the Guides > Hardware & Drivers > Apple Hardware.

    For a list of the standard units of measure and abbreviations used in this developer note, refer to the Hardware Developer Note Terms and Abbreviations.

    Apple offers the following additional resources for video development:

    • Core Video Programming Guide describes the C and Objective-C APIs that support video processing.

    • Getting Started with Graphics & Animation introduces technologies and tools available to developers of applications that process video.
