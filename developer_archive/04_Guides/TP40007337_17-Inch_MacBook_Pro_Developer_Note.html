    Introduction to 17-inch MacBook Pro Developer Note

    Important: This document may not represent best practices for current development. Links to downloads and other resources may no longer be valid.

    This developer note gives a technical description of the 17-inch MacBook Pro computer introduced in February 2008 and incorporating the Intel Core 2 Duo processor on 45 nm process technology. The purpose of this note is to provide information about the computer’s internal design, input-output features, and expansion capabilities to help developers design products compatible with the 17-inch MacBook Pro.

    Organization of This Document

    This document provides a functional block diagram and descriptions of the main components on the logic board of the 17-inch MacBook Pro.

    See Also

    Apple offers the following additional resources for learning about the 17-inch MacBook Pro:

    • Apple's MacBook Pro Support site provides owner manuals, links to support services, and tips for getting the most out of using your 17-inch MacBook Pro.

    • Apple's Specifications site provides technical specifications for recent Mac computers.
