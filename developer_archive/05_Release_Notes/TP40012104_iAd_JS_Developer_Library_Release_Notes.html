    iAd JS Developer Library Release Notes

    This Release Note summarizes changes in this iAd JS documentation release.

    Contents:

    • iAd Producer Documentation
    • New and Updated Documents in This Release
    • Providing Documentation Feedback

    iAd Producer Documentation

    The iAd Producer User Guide and iAd Producer Tutorial no longer appear on the iAd JS Developer Library. The information from those documents has been incorporated into a help file that can be found at: http://help.apple.com/iadproducer/.

    New and Updated Documents in This Release

    iAd Developer's Starter Guide is a new document that provides developers with the information needed to begin coding new rich media iAds.

    iAd Analytics Best Practices is a new document that features best practices for the existing iAd JS analytics framework.

    iAd Certification and Submission Checklist is a new document that explains the iAd certification and submission process and provides criteria for approval.

    iAd Design Guide contains updates and enhancements.

    iAd Tester Installation Guide is a new document that explains how to install iAd Tester to test ads on iOS devices.

    The library also contains new and updated reference documents for iAd JS 1.5 and iAd Producer 2.1. Sort the library document list by date to get a list of the latest changes.

    Providing Documentation Feedback

    To send comments or bugs for a specific document, please use the feedback links available at the bottom of each HTML page. All comments are associated with the document and are screened and routed to the appropriate author and editor for action.

    If you are reading a PDF document on your iPad and are a registered developer, you can file a bug against a doc as well by going to http://bugreport.apple.com and logging in with your iOS Developer account information. Be sure to note the title of the document you are reporting on, as well as the page number and any information that you feel will help us improve the document.
